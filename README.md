\#  Учебная платформа



Онлайн и офлайн платформа для обучения с лучшими преподавателями.  

Проект реализован на React без использования сторонних библиотек для роутинга.



\---



\##  Стек и версии



| Технология | Версия |

|------------|--------|

| Node.js    | 24.21.0 |

| npm        | 10.x |

| React      | 18.x |

| Vite       | 8.3.1 |

| JavaScript | ES6+ |

| CSS Modules | — |



\*\*Важно:\*\* проект написан на \*\*чистом React\*\* без использования `react-router-dom` и других сторонних библиотек для маршрутизации. Навигация реализована через состояние (`useState`).
